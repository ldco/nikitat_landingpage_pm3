# project/

Site-specific layer for nikitat.pro. The framework (`src/lib/`) imports from
here. **To customize this site, edit files here, not framework files.**

- `site-config.ts` — locales, nav, sections, modules, features, admin, logo, brand
- `registry.ts` — project section components (SectionF22)
- `theme.css` — design tokens + utilities
- `content.json` — content seed source
- `SectionF22.svelte`, `HeroParallaxScene.svelte`, etc. — project components
