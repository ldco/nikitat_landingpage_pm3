# PM v3 Full Parity — Port PM v2 to PM v3 by Framework Rules

**Source (PM v2 Nuxt):** `../app-nuxt`
**Target (PM v3 SvelteKit):** current working directory
**Governing rules:** PM v3 framework rules + global engineering rules

---

## ⚖️ Binding PM v3 Framework Rules (MUST apply to EVERY change)

| Rule | Enforcement |
|------|-------------|
| **Design tokens ONLY** | No `text-[14px]`, `max-w-[800px]`, `pt-[calc(...)]`. Use `text-fluid-*`, `max-w-container`, `pt-[var(--pt-section)]` |
| **Tailwind utilities ONLY** | No `<style>` blocks anywhere. No global CSS classes. All visuals in utility classes. |
| **class prop + twMerge** | Every component: `class?: string` prop merged with `twMerge(clsx(...))` |
| **Config-driven everything** | Import `FEATURES`, `MODULES` from `$lib/config/site`. No hardcoded feature flags. |
| **i18n for ALL text** | No hardcoded strings. Every label, message, placeholder, aria-label uses `m.*()` or `$t()` |
| **No type suppressions** | No `@ts-ignore`, `@ts-expect-error`, `@ts-nocheck`, `!` assertions |
| **No empty catch blocks** | Every catch handles or re-throws with context |
| **No raw SQL** | Drizzle ORM only |
| **Zod for inputs** | All API endpoints validate with Zod schemas |
| **CSRF on mutations** | All POST/PUT/DELETE/PATCH protected |

## Risk Register

| Risk | Prob | Impact | Mitigation |
|------|------|--------|------------|
| Design token gaps cause arbitrary-value temptation | High | Medium | Full PM v2 CSS audit BEFORE Phase 5 starts. Add tokens preemptively. |
| Svelte reactivity model mismatch (Vue `watch` → Svelte `$effect`) | Medium | Medium | Test each store/action in isolation before integrating into components |
| Paraglide i18n API differs from Vue I18n `t()`/`te()` | High | Low | Wrap in utility if needed; Paraglide's `m.*()` is simpler |
