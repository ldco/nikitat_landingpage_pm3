### 3.3 Password Hashing Detail

The framework uses **scrypt** (Node.js `crypto.scryptSync`) rather than bcrypt/argon2. scrypt is:
- A memory-hard key derivation function (same family as argon2)
- NIST-recommended (SP 800-132)
- Available natively in Node.js without dependencies
- Configurable with 16-byte salt, 64-byte key length

**Verdict:** Acceptable. scrypt provides equivalent security to bcrypt. Moving to argon2 would be a minor improvement.

### 3.4 Auth Pattern Note

The framework uses **middleware-based auth** (`server/middleware/auth.ts` automatically protects all `/api/admin/*` routes) rather than per-endpoint `requireAuth(event)` calls. This is architecturally superior (can't forget auth on a new endpoint) but differs from the documented API pattern. The `requireAuth` function exists client-side in `useAuth.ts` for UI route guards.
