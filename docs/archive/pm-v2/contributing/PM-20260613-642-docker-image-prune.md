## Summary
Contact form gate: single source of truth toggle + consent storage for 152-FZ/GDPR compliance

## Problem
The contact form visibility was gated by two separate conditions: legal document translation existence AND a showForm config flag. Neither checked the module enabled flag (modules.contact.enabled), creating a dual-source-of-truth problem. Additionally, user consent was validated server-side but never stored in the database, making Art 9 (152-FZ) / Art 7 (GDPR) compliance impossible to prove.

## Solution
1. Added modules.contact.enabled check to SectionContact.vue as the single user-facing toggle for the contact form. The legal docs gate remains as an automatic safety check (not a user setting). 2. Added consent column to contact_submissions schema (Drizzle ORM + SQLite migration) and store the consent boolean on form submission. This provides provable consent records for data protection compliance.
