## Bug 5: Theme store singleton
- **File:** `src/lib/stores/theme.svelte.ts`
- **Issue:** `getTheme()` creates new `$state` every call → multiple ThemeToggle instances have separate states
- **Fix:** Move `$state` to module level (singleton):
```ts
let current = $state<Theme>(getStored() ?? getSystem())
// Then apply theme on first load, add $effect for persistence

  return { get current() { return current }, toggle() {...}, set(t) {...} }
}
```
